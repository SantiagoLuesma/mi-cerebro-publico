El **Prompt Engineering** (o ingeniería de prompts) es la disciplina que se encarga de diseñar, estructurar y optimizar las instrucciones (prompts) que se le dan a un modelo de lenguaje (como GPT o Gemini) para obtener la respuesta más precisa y útil posible.

No se trata solo de "saber preguntar", sino de entender cómo el modelo procesa la información y qué estructuras semánticas reducen las alucinaciones.

## Componentes clave de un buen prompt
1. **Rol/Contexto:** Definir la identidad del modelo (ej: "Actúa como un desarrollador senior").
2. **Instrucción clara:** Qué acción específica debe realizar.
3. **Restricciones:** Lo que *no* debe hacer (ej: "No uses librerías externas").
4. **Ejemplos (Few-shot prompting):** Mostrarle el formato esperado de salida.
